# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please follow responsible disclosure:

- Send an email to the repository owners at `security@local.invalid` (replace with org contact) with a clear description, reproduction steps, and an optional patch.
- If you prefer, open a private issue and mark it `security` (do NOT include secrets or sensitive data in the issue body).

## Supported Versions

This repository follows a minimal support policy: security fixes should be addressed promptly for the `main` branch. End-of-life notices will be posted in the changelog.

## Public Tools

We run automated code scanning (CodeQL) in CI. We also recommend enabling GitHub Secret Scanning and Push Protection at the organization level.

## Contact

Maintainership: open a PR or contact the project owner.
