Accessibility

AutoLearnPro is designed to support an accessible learning experience across its public and authenticated interfaces.

Current accessibility support

Our interface includes semantic page structure, visible keyboard focus, keyboard-operable navigation, responsive layouts, reduced-motion support, and text that can be resized through browser controls.

Ongoing review

Accessibility is reviewed as the platform changes. This page describes current design practices and is not a certification that every page or third-party service fully conforms to a particular accessibility standard.

Report a barrier

If you encounter an accessibility barrier, describe the page, feature, and assistive technology or browser involved so we can investigate.
