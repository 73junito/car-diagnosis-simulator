Synthetic case

Slow cranking after an overnight cold soak

A fictional training vehicle cranks slowly on the first start of the day. The battery is fully charged before testing.

Non-graded practice
Open-circuit battery 12.62 V
Cranking voltage 9.25 V
Positive cable drop 0.18 V
Ground cable drop 0.92 V

  1. Identify the customer concern before deciding what component might be at fault.

    Which statement best defines the concern?

  2. Compare the measured values before choosing a direction. The largest abnormal value is the ground-side voltage drop.

  3. Choose a hypothesis to investigate next. This choice is not scored.

  4. Select the next check you would perform. The demo shows the reasoning workflow, not a hidden answer key.

  5. In a real repair workflow, verification would repeat the operating condition and confirm that the measured fault is no longer present. This public demo intentionally stops before any graded result or stored completion record.

Start with the Concern step. Your selections remain only in this browser session and are not submitted anywhere.
