# OBD-II Codes Dataset for TorqueMind

This folder contains the OBD-II code dataset used by the Car Diagnosis Simulator.

Files:

- `obd2_codes_database.csv` — CSV export of codes and fields.
- `obd2_codes_database.json` — JSON array of code objects.
- `obd2_scenario_seeds.json` — Scenario seed templates referencing codes.
- `ase_code_map.json` — Map of code -> ASE area (e.g. A8, L1).

Note: This commit includes a small sample subset. Replace these files with the full dataset
(`torquemind_obd2_database_bundle.zip`) when ready.
