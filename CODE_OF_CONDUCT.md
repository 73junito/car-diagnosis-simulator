# Code of Conduct

## Our standard

Project participation should be professional, constructive, and focused on improving the work. Contributors are expected to communicate respectfully, review ideas on their technical merits, and make room for questions, disagreement, and correction without personal attacks.

Examples of expected behavior include:

- giving specific, actionable technical feedback
- distinguishing evidence from assumptions
- respecting privacy and confidential reports
- acknowledging uncertainty and correcting mistakes
- keeping reviews focused on the change rather than the person
- following repository security, safety, rights, and governance boundaries

Unacceptable behavior includes harassment, threats, discriminatory abuse, doxxing, deliberate disclosure of secrets or private data, repeated personal attacks, or knowingly circumventing repository safety/security controls.

## Scope

This code of conduct applies in repository issues, pull requests, discussions, reviews, project communication channels, and other spaces where someone is representing the project.

## Reporting conduct concerns

Do not use a public thread to disclose sensitive personal information. Report serious conduct concerns privately to a repository maintainer. Security vulnerabilities should follow `SECURITY.md` instead.

## Enforcement

Maintainers may edit or remove content, restrict participation, close discussions, or take other proportionate action when behavior materially interferes with safe and productive project collaboration.
