Overview

TorqueMind is an automotive diagnostic training platform for CTE programs, instructors, and self-paced learners. It combines realistic fault scenarios, OBD-II reasoning, ASE-aligned workflows, student progress tracking, instructor analytics, and scenario authoring.

Authoring Studio

The Authoring Studio enables instructors to create complete diagnostic scenarios without editing source code.

  1. Configure the vehicle.
  2. Enter the customer complaint.
  3. Add DTCs and freeze-frame evidence.
  4. Configure live OBD-II sensor data.
  5. Define the diagnostic path and root cause.
  6. Map ASE objectives and rubric criteria.
  7. Validate the scenario.
  8. Preview the student experience.
  9. Export JSON.
  10. Import JSON for continued editing.

Scenario JSON

Exported scenarios include vehicle data, complaint, diagnostic evidence, live data, diagnostic path, ASE rubric, and validation-ready structure. JSON files can be shared, backed up, imported, or version-controlled.

Student Guide

  1. Open the Student Dashboard.
  2. Review progress and recommended next steps.
  3. Select a diagnostic scenario.
  4. Review vehicle, complaint, symptoms, DTCs, and live data.
  5. Work through the diagnostic process.
  6. Compare reasoning with the expected diagnostic path.
