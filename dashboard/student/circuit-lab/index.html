Guided practice

  1. Identify the battery as the electrical source.
  2. Locate the main charging protection.
  3. Trace the B+ connection between battery and alternator.
  4. Trace the alternator ground return.
  5. Inject an open charging-feed fault and trace the path again.

Evidence boundary

The charging-cable references above are source-specific Delco Remy values and are not universal charging-system limits. The current field is user-entered and no current is assumed. Open circuits and unrelated ground-path faults do not receive fabricated numeric voltage-drop results. Vehicle-specific authoritative service information is still required for actual charging voltage, alternator output, wiring, procedures, and component limits.
