Overview

TorqueMind is an automotive diagnostic training platform for CTE programs, instructors, and self-paced learners. It combines realistic fault scenarios, OBD-II reasoning, ASE-aligned workflows, student progress tracking, and instructor analytics.

Student Learn Scenarios, transcripts, progress, and learning path.
Instructor Teach Analytics, live sessions, session history, and exports.
Diagnostics ASE Evidence-based diagnostic workflow and skill tracking.
Release v0.5.0 UI modernization and shared framework baseline.

Student Guide

  1. Open the Student Dashboard.
  2. Review progress, learning path, transcript, and recommended next steps.
  3. Use filters to browse available diagnostic scenarios.
  4. Open a scenario and review the customer complaint, symptoms, DTCs, and diagnostic data.
  5. Work through the diagnostic process and compare your reasoning with the expected path.
  6. Return to the dashboard to review performance and next recommended skills.

Instructor Guide

  • Instructor Analytics — review class-level performance and ASE readiness.
  • Live Session — monitor active classroom events in real time.
  • Session History — review and export historical learner activity.

Instructor tools are designed to help identify learners who need intervention, monitor diagnostic confidence, and support evidence-based teaching decisions.

Diagnostic Workflow

  1. Read the complaint carefully.
  2. Identify symptoms and affected systems.
  3. Review DTCs and live data.
  4. Form a testable diagnostic hypothesis.
  5. Verify the fault using available evidence.
  6. Explain the root cause and recommended repair path.
