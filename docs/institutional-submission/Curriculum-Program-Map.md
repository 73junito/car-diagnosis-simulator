## Planning catalog distinction

The repository's broader course catalog is marked `planning` and contains 68 course records:

- 43 undergraduate planning-catalog records;
- 25 graduate planning-catalog records.

The planning catalog is a curriculum-development inventory. It is not identical to either proposed credential structure and should not be read as an approved degree plan.

## Assessment boundary

Curriculum representation does not grant assessment eligibility. Scored institutional assessment, grading, high-stakes use, automatic credential decisions, and governed question-display unlock remain outside the current authorization posture.
