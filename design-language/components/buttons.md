# Buttons

## Purpose

Buttons initiate user actions.

## Variants

- Primary
- Secondary
- Ghost
- Danger
- Icon
- Loading
- Disabled

## Rules

- One primary button per section.
- Never place two primary buttons adjacent to each other.
- Buttons must have descriptive text.
- Icon-only buttons require accessible labels.

## States

- Default
- Hover
- Focus
- Active
- Disabled
- Loading

## Accessibility

- Keyboard accessible
- Visible focus indicator
- Minimum touch target 44x44px

## Testing

- Keyboard activation
- Disabled state
- Focus state
- Loading state
