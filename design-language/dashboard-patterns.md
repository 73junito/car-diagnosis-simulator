# Dashboard Patterns

## Universal Dashboard Pattern

1. Shell navigation
2. Page hero
3. Progress or KPI cards
4. Quick actions
5. Main work area
6. Supporting panels
7. Activity or history
8. Footer

## Student Dashboard Pattern

1. Welcome / current status
2. Progress cards
3. Quick actions
4. Learning path
5. Scenario catalog
6. AI Coach
7. Transcript
8. Performance analytics
9. Activity timeline

## Instructor Dashboard Pattern

1. Class overview
2. Student alerts
3. Assignments
4. Live activity
5. Analytics snapshot
6. Recent submissions

## Analytics Dashboard Pattern

1. KPI cards
2. Filters
3. Charts
4. Session table
5. Export tools
6. Report summaries
