# Accessibility

Accessibility is required for every TorqueMind dashboard and workflow.

## Minimum Standard

TorqueMind targets WCAG 2.1 AA.

## Requirements

- Keyboard navigation for all interactive elements
- Visible focus states
- Semantic heading structure
- Labelled form controls
- Sufficient color contrast
- Non-color status indicators
- Screen reader friendly alerts
- Reduced-motion support
- Responsive layouts that remain usable at mobile sizes

## Dashboard Rule

A dashboard is not complete until it is usable without a mouse.
