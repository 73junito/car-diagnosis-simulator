# Spacing

TorqueMind uses a consistent spacing scale to create visual rhythm across dashboards.

## Scale

- 4px: tight inline spacing
- 8px: compact spacing
- 12px: form and badge spacing
- 16px: standard component spacing
- 24px: section spacing
- 32px: major region spacing
- 48px: page-level spacing
- 64px: large layout separation

## Rules

- Use spacing consistently before creating new values.
- Group related information tightly.
- Separate unrelated dashboard regions clearly.
- Mobile layouts should preserve hierarchy, not simply shrink content.
