# Design Principles

## Clarity First
Every screen must make the primary action obvious.

## Learning Before Browsing
Dashboards should guide students toward progress, not simply list content.

## Consistency Everywhere
Routes, navigation, spacing, buttons, cards, and feedback patterns must be reused.

## Accessibility by Default
Keyboard navigation, focus states, contrast, and semantic structure are required.

## Scalable by Design
New dashboards should be built from shared patterns, not duplicated one-off UI.
