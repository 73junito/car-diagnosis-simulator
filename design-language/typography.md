# Typography

TorqueMind typography must support fast scanning, technical clarity, and accessible learning content.

## Hierarchy

- Page Title: primary screen identity
- Section Title: dashboard region identity
- Card Title: individual content block identity
- Body: explanations and scenario text
- Label: form controls and metadata
- Caption: secondary helper text
- Code/Diagnostic Values: DTCs, voltage readings, scan data

## Rules

- Use clear heading order.
- Avoid multiple competing H1 elements.
- Labels must be visually and semantically connected to controls.
- Diagnostic values should be easy to scan and compare.
